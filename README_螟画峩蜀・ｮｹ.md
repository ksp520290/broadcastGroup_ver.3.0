# 放送班倉庫管理サイト（改修版）について

このzipは、元仕様書（放送班倉庫管理サイト仕様書）をベースに、追加要望を反映した実装です。
要望と仕様書が競合する箇所は、追加要望を優先しています。

## 主な変更点

### 【index.html（閲覧画面）】
- スマホで見やすいように、下にスクロールするとヘッダー（タイトル）部分が自動的に隠れるようにしました。上にスクロール／ドラッグすると再表示されます。
- 自由配置表示・グリッド表示の座標／サイズを、すべて％（パーセント）指定に変更しました（`data/files.json` の `x, y, w, h` は 0〜100 の相対値です）。
- 自由配置カードにも画像を表示するようにしました（`img/` フォルダ内のファイル、または `http(s)://` で始まる画像URLを参照します）。

### 【admin.html（管理画面）】
1. **ログイン機能**
   - ヘッダー右上に「ログイン」ボタンを追加しました。
   - `data/admins.json` に登録されたIDとパスワードが一致した場合のみ、上部ツールバー・サブツールバー・左右サイドバーなどの編集機能が表示されます。
   - 未ログイン時は編集UIを一切表示しない、閲覧専用に近い状態になります。

2. **自由配置アイテムの画像参照化**
   - 自由配置（キャンバス）上のアイテムは単色表示ではなく、`img/` フォルダ（GitHubリポジトリ内 or ローカル）にある画像を自動参照して背景表示します。
   - 右サイドバーの編集パネルから「選択」ボタンでローカルの画像フォルダから画像をアップロードできます。アップロードした画像は一旦ブラウザ内に保持され、「データ」→「GitHub」タブの「GitHubへ保存」を実行したタイミングで、自動的にリポジトリの `img/` フォルダへ格納されます。

3. **編集ON／リサイズの分離（自由配置表示のみ）**
   - 自由配置表示のときだけ「リサイズ」ボタンが追加で表示されます。
   - 「編集ON」のみ：アイテムをクリックすると、グリッド／リスト表示と同様の編集パネル（名称・数量・属性・説明・画像・配置場所など）が右側に開きます。
   - 「編集ON」＋「リサイズON」：ドラッグでの移動・ハンドルでのリサイズができます（値は％で保存されます）。

4. **サイズの％表示化**
   - 自由配置のx, y, 幅, 高さはすべて％で保持・表示・編集します（スマホなど画面サイズが異なる端末でも崩れにくくなります）。

5. **GitHub REST API設定のポップアップ化**
   - 従来左サイドバーに常時表示していたGitHub REST API設定（Owner／Repository／Branch／PAT）は、「データ」ボタンを押した際に開くポップアップ内の「GitHub」タブに移動しました。

6. **上部ツールバーの簡略化**
   - 上部ツールバーは要望どおり、①パンくずリスト ②「通常」 ③「履歴」 ④「ゴミ箱」 ⑤「データ」の5項目のみで構成しています。
     - 「通常」：index.html（通常の閲覧画面）へ遷移します。
     - 「履歴」：history.html（履歴画面）へ遷移します。
     - 「ゴミ箱」：admin.html内でゴミ箱表示モードに切り替えます。
     - 「データ」：CSV／JSON／GitHubの3タブに分かれたポップアップを開きます。右上の「✖」で閉じられます。
   - 検索バー・表示切替（自由配置／グリッド／リスト）・直下／配下切替・編集ON/OFFなどは、上部ツールバーとは別の「サブツールバー」に配置し、上部ツールバーの要件を満たしつつ機能を維持しています。

7. **「データ」ポップアップ（新規要望）**
   - **CSVタブ**：CSVの読込（一時反映）、現在データのCSVエクスポートができます。
   - **JSONタブ**：`files.json` / `histories.json` / `admins.json` を個別にアップロード（一時反映）／ダウンロードできます。
   - **GitHubタブ**：Owner／Repository／Branch／PATの設定と、「GitHubへ保存」ボタン（files.json・histories.json・admins.json・保留中の画像をまとめて保存）を配置しています。

8. **左サイドバー（「≡」ボタンで開閉）**
   - ①管理者一覧：アコーディオンで開閉できます。IDとパスワードの一覧を表示しますが、パスワードは自分がログインに使用したID以外は「••••••••」でマスクされます。各行に「変更」「削除」ボタンがあります（初期管理者アカウントのみ変更・削除不可）。
   - ②管理者追加：ID・パスワードを入力して新しい管理者を追加できます。
   - 管理者情報の追加・変更・削除は、他のデータと同様に「データ」→「GitHub」タブでの保存によって確定します（保存前は一時反映の状態です）。

9. **GitHubのPAT以外の保存方式について**
   - ご要望にあった「PAT等のパスワードを使わないGitHub保存方式」について検討しましたが、ブラウザ単体（サーバーサイド処理なし）で安全にGitHubへの書き込み認可を行う標準的な方法は、現時点では以下のいずれかに限られます。
     - Personal Access Token（今回採用している方式）
     - GitHub Appのユーザー認可コードフロー（サーバーレスでは redirect 後のトークン交換にクライアントシークレットの秘匿が必要なため、静的サイトのみでは安全に実装できません）
     - GitHub Actionsの`repository_dispatch`をWebhook経由で叩く方法（この場合もWebhook起動用のトークンや共有シークレットが必要になり、結局「持っていれば書き込める文字列」を管理者のブラウザに保存する構造は避けられません）
   - そのため、今回はPAT方式を維持しつつ、PATの入力欄をポップアップ内に隠し、通常の閲覧では見えない構成としています。将来的にCloudflare Workers等の軽量なサーバーレス関数を1つ追加できるのであれば、そこにPATを保管し、管理画面からはその関数を叩くだけにする構成（管理者のブラウザにPATを渡さない）に変更可能です。ご希望であれば別途ご相談ください。

- `data/admins.json` を新規追加し、管理者アカウント情報を管理しています。
